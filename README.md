
# Contiguous runs of the NOAA ARL HYSPLIT model

This repository is a work-in-progress (!!) semi-standalone script series
for running the NOAA HYSPLIT model via R for back-trajectory modelling
around Antarctica and the Southern Ocean.

It is intended for long-term analysis of daily releases, either forwards
or backwards.

The current github repo is
<https://github.com/MRPHarris/running-hysplit>.

At present, only the first script is functional.

Download/fork the repository, then work from the .Rproj file using
Rstudio.
